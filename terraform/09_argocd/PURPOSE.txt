# 09_argocd — why this stack exists
#
# Installs Argo CD so the cluster syncs apps from Git (GitOps).
#
# Without it:
#   - No GitOps control plane to deploy kubernetes/ manifests continuously
#
# Run from: Bastion (after 07 + 08 for public UI/DNS)
# Creates:  Argo CD Helm release in namespace argocd
# Used by:  You — create the "easyshop" Application pointing at kubernetes/
#
# UI: https://argocd.simsoliver.com
# App deploy is done in the Argo CD UI (not a Terraform Application resource).
