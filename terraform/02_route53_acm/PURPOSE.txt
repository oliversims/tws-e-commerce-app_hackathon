# 02_route53_acm — why this stack exists
#
# Gives the platform a real domain and HTTPS certificate.
#
# Without it:
#   - No public DNS names (easyshop / argocd / grafana / …)
#   - No trusted TLS cert for the ALB
#
# Run from: PC (after 00_state)
# Creates:  Route 53 hosted zone for simsoliver.com
#           ACM wildcard cert (apex + *.)
# Used by:  08_external-dns (writes DNS into the zone)
#           kubernetes/ingress.yaml (ACM certificate ARN for ALB TLS)
#
# Save after apply:
#   certificate_arn  → put in Ingress annotation if it changed
#   hosted_zone_id   → used by ExternalDNS
