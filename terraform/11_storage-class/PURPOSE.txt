# 11_storage-class — why this stack exists
#
# Defines the default StorageClass policy for EBS volumes.
#
# Without it:
#   - PVCs have no named class / default provisioner policy to request
#
# Run from: Bastion (after 10)
# Creates:  StorageClass "ebs-storage-class" (default)
# Used by:  kubernetes/mongodb-pvc.yaml
#
# Pair with 10:
#   10 = driver that creates volumes
#   11 = policy/name that PVCs ask for
