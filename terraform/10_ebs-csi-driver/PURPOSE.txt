# 10_ebs-csi-driver — why this stack exists
#
# Lets Kubernetes create real EBS volumes for PersistentVolumeClaims.
#
# Without it:
#   - PVCs stay Pending (no volume provisioner for EBS)
#   - MongoDB cannot get a disk
#
# Run from: Bastion (after 06)
# Creates:  IRSA role + AWS EBS CSI driver Helm chart
# Used by:  11_storage-class, then MongoDB PVC in easyshop
#
# Depends on: 04_eks (OIDC)
