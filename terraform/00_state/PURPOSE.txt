# 00_state — why this stack exists
#
# Creates the S3 bucket that stores Terraform state for every later stack.
#
# Without it:
#   - Other stacks have nowhere to save remote state
#   - Bastion cannot download 00_state on first boot (06 uploads a copy)
#
# Run from: PC (first, once)
# Creates:  S3 bucket + versioning + encryption + public-access block
# Used by:  All stacks 01–13 (backend + remote_state where needed)
#
# Keep local file until bastion is up:
#   terraform/00_state/terraform.tfstate
