# 07_alb-controller — why this stack exists
#
# Turns Kubernetes Ingress objects into real AWS Application Load Balancers.
#
# Without it:
#   - Ingress resources do nothing useful in AWS
#   - No public HTTPS entry for Argo CD, EasyShop, Grafana, etc.
#
# Run from: Bastion (after 06)
# Creates:  IAM policy/role (IRSA) + Helm release in kube-system
# Used by:  Every public Ingress (09, 13, kubernetes/)
#
# Depends on: 01_vpc + 04_eks
