# BEFORE YOU START
# ═══════════════════════════════════════════════════════════════════════════════
#
# 1. AWS CLI on your PC (correct account, region us-east-1).
# 2. Terraform installed on your PC.
# 3. Repo cloned locally:
#      git clone https://github.com/oliversims/tws-e-commerce-app_hackathon.git
#      cd tws-e-commerce-app_hackathon
# 4. SSH key pair present (required before 03_keys):
#      terraform/shared/terra-key      — private (never commit)
#      terraform/shared/terra-key.pub  — public
# 5. Docker Hub account with public repos + Access Token (Read & Write):
#      simsoliver/easyshop-app
#      simsoliver/easyshop-migration
#      Create token: Docker Hub → Account Settings → Security → New Access Token
# 6. GitHub classic PAT with repo scope (clone + push manifests) for Jenkins.
#      Create: GitHub → Settings → Developer settings → Personal access tokens
#              → Tokens (classic) → check "repo"

# 7. Jenkins shared library available (pipeline uses @Library('Shared')):
#      https://github.com/oliversims/jenkins-shared-libraries
# 8. Slack incoming webhook URL (required for Alertmanager in stack 13).
# 9. Full first-time deploy: about 60–90 minutes (EKS create is slow).
#
# Command pattern for every stack:
#   cd terraform/<stack-folder>
#   terraform init
#   terraform apply
#
# ═══════════════════════════════════════════════════════════════════════════════
# PHASE 1 — PC STACKS (00 → 06)
# ═══════════════════════════════════════════════════════════════════════════════
# Run from your PC. Apply in this exact order.
#
# --- 00_state ---
# Creates the S3 bucket for all remote Terraform state.
#
#   cd terraform/00_state
#   terraform init && terraform apply
#
# SAVE:
#   terraform output state_bucket_name
#   terraform output state_bucket_region
#
# Keep this file until bastion is up (gitignored):
#   terraform/00_state/terraform.tfstate
#
# REQUIRED — update the S3 backend bucket in EVERY stack providers.tf (01–13)
# to match state_bucket_name from the output above. Search for:
#   bucket       = "tfstate-tws-us-east-1-..."
# Replace with your new bucket name, then continue.
#
# --- 01_vpc ---
#   cd terraform/01_vpc
#   terraform init && terraform apply
#
# --- 02_route53_acm ---
# Route 53 hosted zone + ACM wildcard cert for simsoliver.com.
#
#   cd terraform/02_route53_acm
#   terraform init && terraform apply
#
# SAVE:
#   terraform output certificate_arn
#   terraform output hosted_zone_id
#
# REQUIRED — if certificate_arn differs from Git, update before easyshop deploy:
#   kubernetes/ingress.yaml  →  alb.ingress.kubernetes.io/certificate-arn
#
# If the domain is registered outside AWS, point registrar NS to the Route 53
# zone nameservers (AWS console or zone output).
#
# --- 03_keys ---
#   cd terraform/03_keys
#   terraform init && terraform apply
#
# --- 04_eks ---
# EKS cluster + node group (private API). Takes 10–15+ minutes.
#
#   cd terraform/04_eks
#   terraform init && terraform apply
#
# --- 05_jenkins ---
#   cd terraform/05_jenkins
#   terraform init && terraform apply
#
# SAVE:
#   terraform output jenkins_url
#   terraform output ssh_command
#   terraform output jenkins_get_password_command
#
# Wait 3–5 minutes for install_tools.sh (Jenkins, Docker, Trivy), then do PHASE 1b.
#
# --- 06_bastion ---
# Apply only after 04_eks. Uploads 00_state to S3 for bastion first boot.
#
#   cd terraform/06_bastion
#   terraform init && terraform apply
#
# SAVE:
#   terraform output -raw ssh_command
#
# ═══════════════════════════════════════════════════════════════════════════════
# PHASE 1b — JENKINS: BUILD & PUSH IMAGES
# ═══════════════════════════════════════════════════════════════════════════════
# Do this after 05_jenkins is ready (can overlap with bastion bootstrap).
#
# --- 1. Confirm Jenkins is ready (SSH) ---
#
#   cd terraform/05_jenkins
#   terraform output ssh_command
#
# On the Jenkins host:
#   sudo cloud-init status --wait
#   sudo systemctl status jenkins docker
#   sudo -u jenkins docker ps
#
# If docker fails for jenkins user:
#   sudo usermod -aG docker jenkins && sudo systemctl restart jenkins docker
#
# --- 2. First login ---
#
# Open jenkins_url in a browser (http://<eip>:8080).
# Initial admin password:
#   sudo cat /var/lib/jenkins/secrets/initialAdminPassword
#
# Install suggested plugins → create admin user.
#
# --- 3. Install plugins ---
#
# Manage Jenkins → Plugins.
#
# Note: after "Install suggested plugins", Pipeline is already installed
# (you will see many entries like "Pipeline: Groovy", "Pipeline: Job", etc.
# — there is no separate plugin named only "Pipeline" to add).
#
# On Available plugins, search and install these if not already Installed:
#   - Docker Pipeline
#   - GitHub Integration Plugin   (search: GitHub)
#   - Pipeline: GitHub
#   - Pipeline Utility Steps
#
# Confirm under Plugins → Installed, then restart Jenkins when prompted.
#
# --- 4. Credentials (IDs must match Jenkinsfile exactly) ---
#
# Manage Jenkins → Credentials → System → Global credentials → Add
#
# A) Docker Hub
#    Kind:     Username with password
#    Scope:    Global
#    ID:       docker-hub-credentials
#    Username: <docker-hub-username>   (e.g. simsoliver)
#    Password: Docker Hub Access Token (preferred) or account password
#
#    Access Token:
#      Docker Hub → Account Settings → Security → New Access Token
#      Permission: Read & Write (needed to push images)
#      Use the token as the Password field (not your Hub login password if you use a token)
#
# B) GitHub
#    Kind:     Username with password
#    Scope:    Global
#    ID:       github-credentials
#    Username: <github-username>
#    Password: GitHub Personal Access Token (classic)
#
#    PAT:
#      GitHub → Settings → Developer settings → Personal access tokens
#              → Tokens (classic) → Generate new token
#      Scope:  repo  (covers clone + push of kubernetes/ image tags)
#      Use the token as the Password field
#
# --- 5. Shared library ---
#
# Manage Jenkins → System → Global Trusted Pipeline Libraries → Add
#
#   Name:               Shared
#   Default version:    main
#   Retrieval method:   Modern SCM → Git
#   Project repository: https://github.com/oliversims/jenkins-shared-libraries.git
#
# Save.
#
# --- 6. Pipeline job ---
#
# Dashboard → New Item
#   Name:  EasyShop
#   Type:  Pipeline
#
# Pipeline:
#   Definition:     Pipeline script from SCM ( Source Code Management.)
#   SCM:            Git
#   Repository URL: https://github.com/oliversims/tws-e-commerce-app_hackathon.git
#   Credentials:    github-credentials
#   Branch:         */master
#   Script Path:    Jenkinsfile
#
# Save → Build Now.
#
# Wait for a green build. Confirm on Docker Hub:
#   simsoliver/easyshop-app:<BUILD_NUMBER>
#   simsoliver/easyshop-migration:<BUILD_NUMBER>
#
# Image tags in kubernetes/ must match the build you will deploy
# (easyshop-deployment.yaml and migration-job.yaml), or let the pipeline
# "Update Kubernetes Manifests" stage commit the new tags (needs push access).
#
# ═══════════════════════════════════════════════════════════════════════════════
# PHASE 2 — WAIT FOR BASTION BOOTSTRAP

# Repo on bastion:
